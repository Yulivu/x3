## 0. 协议 P1（主）：留一平台 + 说话人排除的真样本库
- 7 个平台各做一次目标平台；源 = 其余 6 个平台的全部标注 clip。说话人嵌套在平台内（115/122 为单平台），所以自动说话人不相交、平台漂移。
- 目标平台只提供：(i) 一个**真样本库 B**（N 条已验证 bona fide，取自该平台**其它说话人**；对每个 query，库中属于其说话人的 clip 一律屏蔽，距离设 +inf；采样时每个说话人至多贡献 N/4 条）；(ii) 无标签流（即评测 clip，转导式）。库中 clip 不进评测集。**说话人排除同时切断同源相邻片段的匹配。**
- `N ∈ {10, 40, 160}`（目标平台真样本不足时取 ⌊n_real/2⌋，报有效 N）；每个（平台, N）20 次抽样；**头条 N=40**。
- 源平台内部训练也要用同样构造（每个源 clip 的库取自同平台其它说话人）。
- P2 = 原 `strict_draw` / 说话人库口径（连续性，沿用 U8 设定）；P3 = v3 test（冻结后一次，需 `x3/FREEZE_OK`）。
- 指标：每个目标平台的 EER → **7 个平台的宏平均（头条）**；pooled；AUC；**固定 FPR 的 TPR**（库随机分成 proper/calibration 两半，阈值取 calibration 半份真样本的 95%/99% 分位）；转移阈值 HTER；逐平台森林图。
- 两个骨干：`xls-r-2b|S3`、`mms-1b|S3`。区间用平台/说话人聚类自助法（V-1(b)）上的**配对差**。所有门保留 `INCONCLUSIVE` 状态。

## 1. 对手集 BASE_M（信息对等；每个 ≤16 组配置，调参规则相同：源平台内留一说话人 CV）
1. 零样本 Z0；"锚定 Z0"（Z0 分数在库内 Z0 分数中的秩）。
2. 参照距离族：1-NN（OC）、3-NN 均值、质心、top-k、**E-norm-s OC**（已通过 G28）、收缩马氏（协方差用源平台各说话人去均值后合并估计）、OC-SVM / GMM / LOF。
3. 监督：B1（源全部标签）；**B1+refs**（目标库作为额外已标真样本）；监督 kNN（两类，源标签 + 库）；OC+B1 融合（U8 的做法，权重由源内 CV 选）。
4. 目标域适配：PU 学习（见 M-E，同时作基线）、CORAL、DANN-lite、PL（朴素伪标签）、EntMin（理论一致性行，不计入"最强"）。
5. 微调：LP-FT / 末块微调（沿用 W13，`B10_REDUCED` 要标注）。
6. 等预算 few-shot 上限：目标平台 `m` 条真 + `m` 条假（代价上限，不进"最强对手"的取值，单列）。
7. 说话人验证：ECAPA + AS-norm 同构造；平台×语言先验与 Z0 的融合（先验只用训练说话人估）。
8. 可选：PVP 公开代码（JunXue-tech/PVP）的简化版——能在 ≤3h 内跑通才做，跑不通写原因，不阻塞。

## 2. 方法擂台（CPU 为主；每个先写单测再跑）
- **M-A RAP-joint（参照残差分类器）**：对 query x（PCA-256，L2 归一）取库内最近真样本 r*(x)（屏蔽自身说话人），残差 `e = x − r*(x)`；特征 `f = [x, e, c1, c3, cc]`，其中 c1/c3/cc 为 1-NN / 3-NN 均值 / 质心余弦距离，均除以库的留一最近邻尺度 σ̃_B（同 E-norm-s）；L2 正则逻辑回归，C 由源内留一平台 CV 选；训练时每个 epoch 重新采样库，并以 0–30% 概率把库中若干条换成同平台的假 clip（污染增强）。消融：只残差 / 只全局（=B1）/ 关污染增强。
- **M-B LRC（学得的参照条件打分器）**：线性投影 `W ∈ R^{256×64}`；`s(q;B) = Σ_k w_k·d_(k)(q;B)/σ̃_B + b`，其中 `d_(k)` 为第 k 近邻的投影距离（K=10），`w_k ≥ 0` 为学得的名次权重（可退化为 1-NN 或中位数）；BCE 在源平台 episode 上训练：库大小 N∈{10,40,160}，污染率 c∈{0,10,30}%，30% 的 episode 库语言与 query 不同。输出 s，另报与 B1 logit 的 LR 融合版。
- **M-C DB（双库对比）**：假样本库 F = 源平台假 clip 200 条（按平台/语言分层抽）；`s = d_B(q) − d_F(q)`（均按各自库的尺度归一）；变体：F 只取语言匹配的。无训练。
- **M-D 库卫生（对 OC / M-A / M-B 的包装，不单独称方法）**：(i) 孪生剔除——丢掉比库中位留一最近邻距离的 0.5 倍更近的库成员；(ii) 嫌疑参照剔除——留一法看去掉某个库成员后 OC 排序与 Z0 排序的 Spearman 一致性是否异常上升；(iii) 断点意识的 k：`k = ⌈ĉN⌉+1`，ĉ 为库内离群成员比例。污染扫描 c∈{0,10,30}%，m=5 与 N=40 各一组。
- **M-E PU 适配**：每个目标平台训一个线性头（nnPU 风险估计），P = 库，U = 流；先验 π 用核混合比例估计，另报用 Z0 初值的版本；5 个种子。
- **M-F 流结构特征（并入 M-A 作附加特征，也单独评）**：流内最近邻距离（"假样本会重复"，特征 = −log 距离，按库的尺度归一）；以库为种子的个性化 PageRank / 图共识（原 D-2）。
- **M-G 仅真样本的协调化**：对每个（平台, 语言）组只用真样本（源真样本 + 目标库）估计位置/尺度（经验贝叶斯收缩），作用于该组全部 clip，源平台上训练探针后迁移。
- **M-H 共形操作点（不是排序器，叠在最好的打分器上）**：报 FPR 实际值 vs 名义值、TPR@5%/1%FPR、HTER。
- **选择规则（写定，在 P1-dev 上选，不用 test）**：以两个骨干在 N=40 上"7 平台宏平均 EER"的平均值选 M*；复杂方法要比简单方法低 ≥0.5 才算胜出，否则取简单的。

## 3. 门
- **G40 `SOTA_PASS`**：M* 对 BASE_M 中最强的一个（第 6 项除外），N=40：宏平均 EER 在**每个骨干上**低 ≥1.0，配对 (b) 区间排除 0，且**参与宏平均的平台中至少 70%（向上取整，且 ≥4 个）**更好（dev 上真假各 <30 条的小平台不进宏平均，所以不能硬写"7 个里 ≥5 个"）；N=10 不差于它。P3（test，冻结后一次）上方向一致且区间排除 0 → 最终判定。点估计过阈但区间含 0 → `INCONCLUSIVE`。
- **G41 `METHOD_CARD`（技术贡献的可判版本）**：写 `x3/method_card.md`：(T1) ≤15 步的算法框，用到的每项信息都是标准输入或由输入算出；(T2) 计算件及其"有代理真值"的准确率表（例如污染检测的精确率/召回率，或学得的名次权重与"真值最优"的差）；(T3) 运行 test 之前写定的两条预测——失效边界（语言不匹配；污染 >50%）与剂量反应（增益随"源—目标平台真样本分布的距离"增大，报 Spearman）；(T4) 在主表里对 naive 修法最强的一个（OC / E-norm-s OC / B1+refs / OC+B1）的差 > 标准差。
- **G42（信息性）稳健性**：c∈{0,10,30}% 污染下 M* 相对 1-NN 与相对 Z0 的差；语言不匹配子集上相对 Z0 的差。
- **判停**：到 **10-18 晚**没有任何方法过 G40（含 INCONCLUSIVE）→ 写 `DECISION_POINT_4.md` 等 hongyu，不要自行加方法。

## 4. 对照（GPU 车道，非阻塞，擂台并行；结果只报告，不是门）
1. **编码归一化**：所有 clip 经同一条链（16k 单声道 → AAC 64 kbps → 解码）重提两个骨干的特征，重算 Z0、OC、M*；报增益保留比例。
2. **反事实面板**：取真样本子集（每平台 ≤500 条）：(a) 声码器重合成（两个公开声码器，如 Vocos / HiFi-GAN）；(b) 信道扰动（AAC / Opus / MP3 / 限带 / 响度 / 加噪，随机链，库与 query 各自独立）。报 ΔOC、ΔZ0 与"真 vs 假"间隔的对比。
3. **非后训练特征**：原始 XLS-R / WavLM 逐层特征与手工描述符（对数梅尔均值/方差、带宽、响度、时长、SNR）上做同样的最近邻，报增益。
4. **跨平台 / 跨语言库**：08 的 D-1、D-3（库规模曲线）按 P1 重做一遍。
